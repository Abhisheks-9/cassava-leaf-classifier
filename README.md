# Cassava Leaf Disease Classifier

A CNN-based image classifier that identifies disease type in cassava leaf images
(5 classes) using transfer learning with ResNet152 in PyTorch.

> Status: work in progress — this README will be filled in with results, metrics,
> and sample predictions as the project is rebuilt from the original notebook.

## Project structure

- `src/` — training and inference code
- `notebooks/original_exploration.ipynb` — original EDA and prototyping notebook
- `app/` — demo app for interactive predictions
- `assets/` — sample outputs (confusion matrix, Grad-CAM, predictions)

## Setup

```bash
pip install -r requirements.txt
```

## Dataset

[Cassava Leaf Disease Classification (Kaggle)](https://www.kaggle.com/c/cassava-leaf-disease-classification)
